EduSphere

Plateforme scolaire modulaire pour élèves de 7 à 10 ans. Cette adresse GitLab Pages affiche la vitrine du projet.

Ouvrir l'application Voir le code GitLab

📱 Application complète

La connexion élève/prof, les exercices, examens et corrections tournent sur un serveur Laravel (PHP + base de données). GitLab Pages ne peut pas exécuter Laravel directement.

💻 Développement local

Sur ton PC : php artisan serve puis ouvre http://127.0.0.1:8000/connexion. Comptes démo : prof / ali.

🚀 Mise en ligne

Utilise le job GitLab deploy:production vers un VPS, ou un hébergeur PHP (Railway, Render, Hostinger).

Configure la variable CI/CD APP_URL (ou PAGES_APP_URL) avec l'adresse de ton serveur Laravel pour que le bouton « Ouvrir l'application » pointe vers la vraie app.
